# EDA – Exploratory Data Analysis Using Python

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on sales data to identify customer purchasing patterns, product trends, and business insights.

### Objectives

- Perform data cleaning and manipulation to prepare the dataset for analysis.
- Conduct Exploratory Data Analysis (EDA) using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.
- Analyze customer demographics across different states, occupations, gender, and age groups to understand customer purchasing behavior and improve customer experience.
- Identify the best-selling product categories and products to support inventory planning, optimize stock availability, and meet customer demand.
- Generate actionable insights to support data-driven business decisions and improve sales performance.
